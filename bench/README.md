# 评测与消融（bench/）

这一层回答一个问题：**"峰哥体"到底能不能被度量，以及蒸馏规则与语料检索到底值多少。**
它全部是**包外**脚本（联网、要 API key），不进 npm 包，也不参与 DSH Store 的插件契约。

```bash
# 0) 一次性：模型与价格
node bench/lib/deepseek.mjs --models        # 确认可用模型（本机：deepseek-flash / deepseek-v4-pro）

# 1) 生成：30 题 × 4 档 = 120 次调用（结果冻结在 bench/runs/<runId>/，可续跑）
node bench/generate.mjs --dry-run --only p01            # 先看拼出来的 prompt，不花钱
node bench/generate.mjs --concurrency 4

# 2) 自动指标 + real 对照
node bench/metrics.mjs --run <runId>

# 3) 消融对比表 + 成本表（从真实产物生成，不手抄）
node bench/ablation.mjs --run <runId>

# 4) 100 条评测集
node bench/items.mjs --run <runId>

# 5) 盲评表（人工）+ 胜率/κ
node bench/labels.mjs sheet --run <runId>
node bench/labels.mjs score --answers <你导出的 json>
```

## 一、四档条件

| 档 | 给模型什么 | 说明 |
|---|---|---|
| `c0-base` | 只有"帮博主写微博"一句 | 基线 |
| `c1-distilled` | SKILL.md **全文**（约 2.2 万字） | 蒸馏规则档 |
| `c2-retrieval` | SKILL.md + **BM25 检索到的 top-8 真实语料** | 检索增强档 |
| `c3-lora` | 微调 | **未运行**，见 [`LORA.md`](LORA.md) |
| `neg-formal` | "正式书面评论撰稿人" | 硬负例来源，不参与排名 |

30 条选题（`prompts.jsonl`）四档共用，**逐题配对**——同一道题在四档下各生成一次，这样才谈得上"可比"，
也让盲评能做成 A/B 二选一。

## 二、实测结果（run `run-2026-10-12T05-25-39`，模型 `deepseek-flash`，temperature 1.0，thinking 关闭）

| 档 | n | 中位字数 | lint 不通过↓ | 统计带内率↑ | 风格 JSD↓ | 风格 MAE↓ | distinct-3 | BLEU | ROUGE-L | 最长照抄 | 成本/次 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `c0-base` | 30 | 118 | 27% | 40% | 0.35 | 0.13 | 0.96 | 0.03 | 0.16 | 7 字 | $0.000057 |
| `c1-distilled` | 30 | 56 | **10%** | **60%** | **0.20** | 0.09 | 0.89 | 0.02 | 0.17 | 15 字 | $0.000093 |
| `c2-retrieval` | 30 | 68 | 20% | 47% | **0.18** | 0.10 | 0.93 | 0.12 | 0.23 | **20 字** | $0.000168 |
| `c3-lora` | — | — | — | — | — | — | — | — | — | — | — |
| **_real 对照_** | 30 | 51 | 7% | 90% | 0.05 | 0.03 | 0.94 | 0.27 | 0.27 | 13 字 | — |

> real 对照＝从语料随机抽 30 条真帖，按**自身文本**检索参考（剔除自身）后算同一批指标。
> 它是这些指标在这项任务上的**天花板**，没有它就不知道"60% 带内率"算好还是算差。

生成本身：120 次调用、0 条截断、总成本 **$0.0122**（约 ¥0.09），平均 1.35 s/条。
输入 token 里 **97% 命中缓存**——规则档每次要灌 1.5 万字左右的 SKILL.md，
但因为前缀相同会命中缓存，命中价是未命中的 1/50，所以"规则很贵"是错觉：真正的成本大头是输出。

## 三、结论（含**反直觉**的那几条）

1. **蒸馏规则确实有用，且很显著。** 相对基模：lint 不通过率 −63%（27%→10%）、风格 JSD −42%、统计带内率 +50%。
   最直观的例子（题目 p05「公司强制要求所有人学会用 AI 工具」）：
   - `c0-base`：129 字的议论文，"工具是为人服务的，什么时候变成考核的枷锁了？"
   - `c1-distilled`：33 字的峰哥体，"学了不会扣绩效，学会了的建议开除，因为马上就会发现这活一个人干就够"
   同一个模型、同一个温度，只换了 system——差的不是文采，是**语域**。

2. **检索增强没有变好，反而在行为指标上变差了。** `c2` 相对基模仍改善（lint −25%、JSD −49%），
   但**两项都输给不带检索的 `c1`**（lint 20% vs 10%、带内率 47% vs 60%）。
   它只在**字面重合**上更高（BLEU 0.12 vs 0.02、ROUGE-L 0.23 vs 0.17）。
   自洽的解释：few-shot 例子的表面特征把规则稀释了——模型在学例句，不是在守规则。

3. **检索增强把"像他"拽向了"抄他"。** 最长连续照抄片段：`c1` 15 字、**`c2` 20 字**，而 real 对照只有 13 字
   （且那 13 字是平台水印"峰哥亡命天涯的微博视频"，不是文风）。`c2` 抄的 20 字是：
   > 「抽一部iPhone 17，5499元这个」 ← 出自「日子不过了，现在就开始抽，抽一部iPhone 17，5499元这个。转发+关注就…」

   即**整句搬走了抽奖模板**。`c1` 那 15 字则是免责句「。个人观点，不构成投资建议。」
   ⇒ 检索增强需要一条硬约束：**照抄长度不得超过 real 对照同量级**。

4. **规则档最大的偏差恰好是这个账号历史上的第一大 AI 味来源。** `c1` 有 **40%** 的帖子挂了免责声明，
   而语料里只有 **0.6%**（+39.4pt，是本档最大的单项偏差）。
   SKILL.md 本身写的上限是"每 5 条最多 1 条"（20%），模型**超额一倍执行**；
   而 20% 本身也仍是语料的 33 倍。`c2` 好一些（23.3%），但仍在同一量级。
   这条是可直接动手修的：把免责句从"条件规则"改成**默认不写 + 只在写了具体点位/价位时考虑**，
   并在 lint 里按批次统计而不是按单条判。

5. **长度是本档第二大偏差，且靠规则治不了。** 语料短帖中位 41 字，`c1` 56、`c2` 68、`c0` 118。
   带内率的偏差点里，`短帖(15-50)` / `中帖(51-103)` / `长帖(>103)` 常年带外——
   模型有强烈的"把话说完整"的倾向。lint 现在只对"超出 p90"报 WARN，**对纠偏力度不够**。

6. **BLEU 在这项任务上会给出错误排名。** real 对照 BLEU 0.27，`c2` 0.12，而行为指标最好的 `c1` 只有 **0.02**
   —— 比基线的 0.03 还低。若按 BLEU 排名，会得出"加了规则反而更像基模"的荒谬结论。
   BLEU/ROUGE 测的是字面重合，不是风格。报表里保留它们，但**不用于排名**，只作为"有没有整句照抄"的旁证。
   真正有区分力的是 lint 通过率、统计带内率、风格 JSD 这三项行为指标。

7. **distinct-3 反向印证了规则的约束力**：`c1` 0.89 最低（句式更收敛），`c0` 0.96。
   注意这是"约束生效"的证据，不是"质量更好"的证据。

## 四、边界（这套评测**测不了**什么）

- **测不了"像不像真人"**。上面全是与语料分布的统计距离；"读起来像不像他"只能靠人工盲评
  （`bench/labels.mjs` 的成对 A/B）。自动指标过了不等于像。
- **30 题是一批，不是分布**。带内率本身有抽样误差（合成区间已放宽），跨档比较要看成对差异，别抠 1–2 个百分点。
- **单模型结论**。全部数字来自 `deepseek-flash` 一个基座。换基座结论可能变——尤其第 1 条的量级，
  因为基模先验里已经存了多少"峰哥"是未知量（`c0` 写出的"满仓/吃面/A股钉子户"说明先验不弱）。
- **`neg-formal` 是构造出来的负例**，不代表真实世界的负例分布。
- **成本按 off-peak 价算**（本次运行时刻不在 peak 时段），且**不查中国法定节假日**，跨节假日会高估。
- **没测 prompt 注入/越狱/隐私**——那在 [`../security/`](../security/) 里单独测。

## 五、文件

| 文件 | 作用 |
|---|---|
| `prompts.jsonl` | 30 条固定选题（四档共用） |
| `lib/deepseek.mjs` | 零依赖 API 客户端（key 从 env / `$DSH_HOME/.credentials.yaml`；**不打印 key**） |
| `generate.mjs` | 四档生成，冻结产物 + usage，可 `--resume` |
| `metrics.mjs` | 自动指标（lint 率 / 带内率 / JSD / MAE / distinct-n / BLEU / ROUGE-L / 照抄检测）+ real 对照 |
| `items.mjs` | 100 条评测集（含出处与弱标签） |
| `labels.mjs` | 盲评表（HTML + CSV）与胜率 / Cohen κ |
| `ablation.mjs` | 消融对比表与成本表（从产物生成） |
| `pricing.mjs` / `pricing.json` | **唯一**的价格来源与成本算法（service 也用这一份） |
| `lora.mjs` / `LORA.md` | 微调数据导出与可执行协议（**未运行**） |
| `report/` | 生成的报告（`ablation-*.md`、`label-sheet.html`、`pair-key.json` 等） |
| `runs/` | 冻结的生成结果（逐条 raw 输出 + usage） |
