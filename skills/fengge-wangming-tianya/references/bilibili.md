> 数据源：B站搜索（8 个关键词 × 3 页去重）+ AI 字幕 + 弹幕分段接口。
> 采集脚本与本报告同目录：`fg_bili_collect.js` → `fg_bili_harvest.js` → `fg_bili_dm_seg.js` → `fg_bili_speech2.py`。
> **这是本项目第一次接入微博之外的语料源。** 微博是「他写什么」，B站是「他说什么」——两套语域，别混着用。

## 一、这个生态长什么样

**237 条**命中视频，去掉标题不含「峰哥」的搜索噪声后 **201 条**，分布在 **116 个第三方 UP主 + 官方号**上。

| 指标 | 值 |
|---|---|
| 官方号「峰哥亡命天涯」自投 | 3 条 / 784 万播放 |
| 第三方（切片号 / 录播号 / 搬运） | 234 条 / **7,223 万播放** |
| 第三方播放中位 | 28,905 |
| 时长中位 | 14 分钟（>20 分钟的 **101 条**，<60 秒的仅 10 条） |
| 标注「回放 / 录播 / 直播」 | 51 条 |

**第一条结论：这不是短视频切片生态，是长视频生态。** 中位 14 分钟、上百条超 20 分钟——切片号干的是"把整场直播搬过来"，不是"剪 15 秒卡点"。这直接决定了语料可得性：**有整场逐字稿可拿**。

> 但也可能误杀了个别真内容。门槛是**可调参数**，不是结论。

## 三、⚠️ 字幕口径三坑（不修的话整份语料是废的）

这三条都是实测撞出来的，**任何人复现这条链路都会踩**：

### 坑 1：B站 AI 字幕是「滚动窗口」，不是逐句

相邻条目内容重叠，同一句话滑着出现三次：

```
呃看看啊你还知道直播呀对呀这不来播了吗
你还知道直播呀对呀这不来播了吗现在已经
对呀这不来播了吗现在已经终于找到你了
```

**直接 `''.join()` 会虚增约 1.8 倍字数**，而且会把"金句"算成拼接怪。
**修法**：维护累计串 `acc`，对新窗口 `w` 求「`acc` 的最长后缀 == `w` 的最长前缀」的长度 `k`，只追加 `w[k:]`。

### 坑 2：长视频里混入他人音轨

有一条 14,407 字的「峰哥谈三礼」，前半段是**英文歌词 + 英雄联盟解说**（"酒桶炸了一下""GG 的优先选边选择了蓝色方"）；
一条标着「峰哥连麦中医魔怔粉丝」的，字幕通篇是 **SEVENTEEN 团综**（还带着字幕组批注 `[喜欢C位的香蕉组长]`）。

> 这是 UP主把多段素材拼进一条视频造成的：**AI 字幕按音轨生成，不管那条音轨上的人是不是峰哥。**

**修法（两层）**：
1. **段落级**：剔除英文字母占比 >35% 的段，以及「命中噪声词数 ≥2 且多于峰哥特征词数」的段。
2. **视频级**（关键）：算整条的「峰哥特征词/万字」密度，**低于阈值整条丢弃**。段落级过滤挡不住这种污染，必须视频级兜底。

### 坑 3：同一份字幕资产挂在多条视频上

切片号互搬同一段素材，B站对相同音轨**复用同一份 AI 字幕**。实测一份 16,587 字的字幕同时挂在 4 条不同 UP主、不同标题的视频上。
**修法**：按重建后文本的 md5 做视频级去重（154 → 53）。

### 附带一项：接口通道

| 接口 | 状态（2026-09-24 实测） |
|---|---|
| `x/player/v2` 取字幕轨 | ✅ 通。**必须登录**才有 `ai-zh` 轨，未登录返回空列表 |
| 字幕正文 `aisubtitle.hdslb.com/...` | ✅ 通，带 Cookie + Referer 即可 |
| `x/v1/dm/list.so` 取弹幕 | ❌ **密集请求后返 412 风控**（登录与否都一样） |
| `x/v2/dm/web/seg.so` 取弹幕 | ✅ **通**，protobuf，需自己解（`1=progress_ms, 3=mode, 7=content`） |
| `x/player/wbi/playurl` 取音频流 | ✅ 通（未登录也能拿到 192kbps 音轨，可做 ASR 兜底） |

> 关于登录：**未登录也能拿到弹幕与音频流**，但 ①字幕轨拿不到 ②密集请求很快撞 412。
> 登录后视频码率从 480p 解锁到 1080p/1920p，且字幕轨出现。**这条链路上"登录"是必需品，不是加分项。**

## 四、口语 vs 微博：同一个人的两套语域

| 标记 | 微博（每万字） | 直播（每万字） | 方向 |
|---|---|---|---|
| 为什么 | 5.2 | 7.3 | 直播高 1.4× |
| **对吧** | 0.1 | 4.9 | **直播高 59×** |
| **对不对** | 0.3 | 2.7 | **直播高 11×** |
| **我跟你说** | 0.1 | 1.6 | **直播高 19×** |
| 家人们 | 2.2 | 1.2 | 微博高 1.8× |
| 太吓人了 | 1.0 | 0.3 | 微博高 3.3× |
| 不构成（投资建议） | 0.8 | 0.1 | 微博高 5.2× |
| 个人观点 | 0.5 | ~0 | 微博专属 |

**读法（这条最关键）**：

- **「对吧 / 对不对 / 我跟你说」是直播的呼吸，不是微博的**。它们占直播口语极大比重，但在**微博全量 118k 字里几乎不出现**。
  ⇒ **写微博时加这三个，会立刻露馅。** 它们是"连麦对线"的场景产物（需要对方回应），微博是单向广播，用不上。
- **「家人们 / 太吓人了 / 免责句」反过来是微博的**。免责句（个人观点，不构成投资建议）是**写**出来的落款，他直播里基本不说。
  ⇒ 这一条修正了一个常见误解：**免责句不是他的口头禅，是他的书面收尾件。**
- **「为什么」两边都高**（7.3 vs 5.2）——它是跨语域的真口头禅。**这一条可以放心用。**

## 七、弹幕：观众在他的直播里做什么（50,884 条 / 45 条切片）

采集通道是 `seg.so`（`list.so` 撞 412，见第三节）。**弹幕中位 6 字**——比他微博热评（中位 12 字）还短一半，是纯条件反射式的。

| 高频弹幕 | 次数 | 读法 |
|---|---|---|
| 哈哈哈哈哈（各长度合计） | ~5,700 | 笑是绝对主频，占全部弹幕 **18.5%** |
| **这是好事啊**（含「这是好事儿啊」「这是个好事啊」变体） | **~1,200** | **他的标志性口头禅被观众当口号复读** |
| ？/？？/？？？ | ~1,500 | 集体问号，荒诞时刻的标配反应 |
| 还真是 | 326 | 认同类里最靠前 |
| **稳健医疗 / 300888** | **237 / 233** | **弹幕在刷股票代码——持仓标的成了应援口号** |
| 逆天 | 196 | |
| 压抑了 | 150 | 复读他的"性压抑论"标签 |
| 抓心挠肝了 | 73 | 复读他的口癖 |

**三条结论：**

1. **「这是好事啊」是他被观众认领得最牢的一句**（复读量约为第二名的 3.7 倍）。写微博需要"一秒被认出来是他"时，这句的识别度最高。
2. **观众刷股票代码（稳健医疗 300888）** —— 说明他的**具体持仓标的**已进入观众记忆，成为应援物。这给"持仓晒单"这个动作加了一层外部证据：晒单不只是自我标榜，还是**观众参与方式**。
3. **弹幕里没有争论**：骂/质疑类只占 **0.9%**，捧/认同类 7.6%。对比微博热评生态（从"吵架现场"变"股友会"），B站弹幕**更彻底**——只剩起哄与复读，连吵架都没有。
   ⇒ **别把"观众会来骂他"当预期。** 两个平台的观众都是来看/跟着乐的，不是来辩论的。

> ⚠️ 又一处平台差异：微博热评里 **科技类词翻七倍**（见 `evolution.md` 第六节），而 B站弹幕里科技类只占 **0.6%**。
> **同一个"科技/AI"选题，在微博激起讨论、在B站激不起水花。** 选题要看平台。

## 八、对写稿的启示（可直接执行）

1. **B站语料只用来校准"他的思维方式"，不要拿来当微博文案模板**——两套语域的标记词几乎不重叠（见第四节）。
2. **要"直播味"的句子，只能用**：为什么…？、我跟你说、说白了、你懂不懂。**不能用**：对吧、对不对（那是互动产物）。
3. **写"相亲/男女"题材的微博前先掂量**：B站那边占比 15.8%，微博那边 2026 已退到个位数条。**同一个话题在两个平台的分量完全不同。**
4. **宁德/电池/算力是他直播里的高频硬科技锚点**，微博侧可以少写，但作为"人设一致性"背景要知道。
5. **想要更多语料**：录播号在逐日搬整场（166~213 分钟/条），这条路可持续增量，且**字幕只有 9 月前后那批有，更早的没有** ⇒ **要存趁早**（AI 字幕可能像转发原文一样会消失）。
